\## 📚 Knowledge Acquired / Conocimiento Adquirido



\### Git \& GitHub

\- `git init` — initializes a local repository

\- `git config --global` — sets global identity (name, email)

\- `git remote add origin <url>` — links local repo to GitHub

\- `git add .` — stages all changes for commit

\- `git commit -m "message"` — saves a snapshot with a message

\- `git push -u origin master` — pushes to GitHub and sets tracking branch

\- `git rm --cached <file>` — removes a file from tracking without deleting it

\- `.gitignore` — file that tells Git which files/folders to ignore

\- Personal Access Token — required for GitHub authentication (replaces password)

\- Commit messages in English, imperative style: `"docs: update README"`



\### Python \& Environment

\- Anaconda manages Python environments and packages

\- Jupyter Notebook creates interactive `.ipynb` files

\- `import pandas as pd` / `import numpy as np` — standard data imports

\- `pd.read\_csv(path, encoding="latin-1")` — loads CSV with special characters

\- `df.shape` — returns (rows, columns)

\- `df.head()` — shows first 5 rows

\- `df.columns.tolist()` — lists all column names

\- `df.dtypes` — shows data type of each column

\- `df.isnull().sum()` — counts missing values per column

\- `df.groupby("col")\["col2"].sum().sort\_values(ascending=False)` — group and rank



\### Repository Strategy
